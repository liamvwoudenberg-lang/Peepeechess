@TITLE@ - ALPHA BUILD   (commit @SHA@)
=================================================
The full Peepeechess application: main menu, Classic Chess, Battle Chess (a capture starts a real-time third-person
fight), settings and the online screens. Online play needs a running Peepeechess server/backend; offline play
(local Classic and local Battle Chess, vs a friend on the same PC) works without anything.

START
  Windows : double-click @NAME@.exe
            (Start-with-console.bat opens it with a console window that prints errors - attach that output when
            reporting a bug). Keep the .exe, the .console.exe and the .pck in the SAME folder.
            Windows SmartScreen may warn about an unsigned app: "More info" -> "Run anyway".
  Linux   : ./@NAME@.x86_64

CHESS
  Click a piece, then a highlighted square (or drag). Right-drag / wheel orbit and zoom in the 3D view.
  Battle Chess: when a capture is attempted the two pieces fight; the winner keeps the square.

COMBAT CONTROLS (local Battle Chess; White = P1, Black = P2)
  Action                    P1 keyboard + mouse    P2 keyboard      Gamepad (Xbox / PS4 labels)
  Move                      W A S D                Arrow keys       Left stick
  Light attack (x3 combo)   LMB or F               J                X / Square
  Heavy attack              RMB or G               K                Y / Triangle
  Block (hold)              Q                      U                LB / L1
  Parry (tap just before    E                      I                RB / R1
    a hit lands)
  Dodge (hold a direction)  Space                  L                A / Cross
  Special ability           R                      O                B / Circle
  Sprint                    Shift                  Ctrl             LT / L2
  Lock-on                   Tab / middle mouse     P                L3 (stick click)
  Camera                    Mouse (captured)       , and .          Right stick
  F11 = fullscreen.

WHAT THIS BUILD IS - AND IS NOT
  * Real: Codex's chess rules and application, the authoritative combat rules for Pawn, Knight, Bishop, Rook and
    Queen (the King and the tuned balance data are in the code, not yet selectable in the app), combat polish
    (trails, hit/parry/dodge effects, hitstop), procedural sound, 6,800+ automated checks on the code.
  * NOT in this build yet: the trapdoor/pit transition (a capture currently shows the older arena overlay), two PS4
    controllers in the application's Battle Chess (only keyboard seats there; gamepads work in the standalone
    arena), the controls-rebinding screen, a computer opponent for Classic Chess.
  * Never run on a real Windows machine or a real gamepad by the developers; the Windows build is produced with the
    official export templates and only the Linux build has been executed (headless / software rendering).
  * Balance and feel are unvalidated by human play. Visuals are generated placeholder-quality art.
