# Classic board assets

`legions-drawn.png` is copied unchanged from the existing project asset
`public/pieces/legions-drawn.png`. The SVG source and generation scripts remain
in their original locations. Six columns: pawn, knight, bishop, rook, queen,
king; rows: royal White/Black, elves White/Black, skeletons White/Black.
The native Classic board uses royal rows for both sides. No combat asset is used
or modified. The 3D board builds actual role-specific meshes in GDScript.
